================================================================================
                    INSTRUCCIONES DEL SITIO WEB
          Guía Completa para Entender, Modificar y Mantener el Sitio
================================================================================

Este documento es una guía completa para administrar, modificar y mantener este
sitio web profesional de un Ingeniero Estructural.

================================================================================
1. EXPLICACIÓN GENERAL DEL PROYECTO
================================================================================

EL PROYECTO EN RESUMEN:
Este es un sitio web profesional de cartera (portafolio) para un Ingeniero
Estructural. El sitio presenta servicios, proyectos, un blog, información de
contacto y recursos descargables.

ARQUITECTURA DEL SITIO:
- Arquitectura de SITIO ESTÁTICO: Todas las páginas son archivos HTML simples
  que se pueden publicar directamente sin servidor backend.
- Construcción con VITE: Proyecto configurado con Vite (herramienta de
  construcción moderna) para desarrollo y bundles optimizados.
- Diseño RESPONSIVE: El sitio se adapta automáticamente a móviles, tablets y
  computadoras de escritorio.
- Sistema de TEMA CLARO/OSCURO: Los usuarios pueden cambiar entre tema claro
  y oscuro con un botón en el menú.
- Navegación MÓVIL AMIGABLE: Menú hamburguesa en dispositivos móviles que
  desaparece en desktop.

FLUJO DEL SITIO:
1. Usuario entra a /index.html (página principal)
2. Puede navegar a través del menú principal (Inicio, Sobre mí, Servicios,
   Proyectos, Blog, Recursos, Contacto)
3. Cada página tiene el mismo header, navegación y footer
4. Los estilos se cargan desde /assets/css/
5. Las funcionalidades interactivas se cargan desde /assets/js/

2. ESTRUCTURA DETALLADA DEL PROYECTO
================================================================================

CARPETA: assets/css/
────────────────────────────────────────────────────────────────────────────

main.css (295 líneas)
  Propósito: Define todo el sistema de diseño del sitio
  Contiene:
    - VARIABLES CSS: Colores, espaciados, tipografía, sombras, transiciones
    - Reset CSS: Estilos base para todos los elementos
    - Tipografía: Tamaños, pesos, alturas de línea
  Qué modificar: Los colores, tipografías, espaciados
  NO modificar: La estructura de las variables

  VARIABLES IMPORTANTES A PERSONALIZAR:
  --color-primary: #1e3a5f       (Color azul principal)
  --color-secondary: #4a6fa5     (Color azul secundario)
  --color-accent: #e67e22        (Color naranja de énfasis)
  --color-text: #2c3e50          (Color del texto)
  --font-primary: 'Inter'        (Fuente principal)
  

layout.css (347 líneas)
  Propósito: Estructura general del sitio
  Contiene:
    - Container (contenedores con ancho máximo)
    - Header y navegación
    - Sistema de grid (grid-2, grid-3, grid-4)
    - Secciones comunes
    - Footer
  Qué modificar: Espaciados, ancho máximo del contenedor
  NO modificar: Las clases base del sistema


components.css (430 líneas)
  Propósito: Componentes reutilizables
  Contiene:
    - Botones (.btn, .btn-primary, .btn-secondary, .btn-accent)
    - Cards (.card, .card-content, .card-title)
    - Formularios
    - Badges y etiquetas (.tag)
    - Timelines (para experiencia y formación académica)
  Qué modificar: Colores, tamaños, efectos hover
  NO modificar: Las clases base


responsive.css (393 líneas)
  Propósito: Hace el sitio responsive para todos los dispositivos
  Contiene:
    - Media queries para diferentes pantallas
    - Breakpoints: Mobile (<768px), Tablet (768-1024px), Desktop (>1024px)
    - Ajustes de navegación móvil
    - Stack de elementos en móvil
  Qué modificar: Los breakpoints si es necesario
  NO modificar: A menos que necesites cambiar el comportamiento responsive


CARPETA: assets/js/
────────────────────────────────────────────────────────────────────────────

main.js (326 líneas)
  Propósito: Funcionalidades generales del sitio
  Maneja:
    - Animaciones al hacer scroll (elementos se ven con efecto)
    - Lazy loading de imágenes (cargan cuando entran en vista)
    - Validación de formularios
    - Utilidades generales
  Qué modificar: Umbrales de animación, validaciones
  NO modificar: La lógica base de scroll animations


navigation.js (177 líneas)
  Propósito: Sistema de navegación
  Maneja:
    - Menú móvil (hamburguesa)
    - Indicador de página activa (resalta el link actual)
    - Efecto scroll en header (sombra cuando scrolleas)
    - Smooth scroll hacia elementos
  Qué modificar: Tiempo de transiciones
  NO modificar: Las clases de toggle


theme.js (187 líneas)
  Propósito: Sistema de tema claro/oscuro
  Maneja:
    - Cambio entre tema claro y oscuro
    - Guardado de preferencia del usuario en localStorage
    - Detección de preferencia del sistema
    - Aplicación de variables CSS según el tema
  Cómo funciona:
    1. Usuario hace clic en botón tema (con clase .theme-toggle)
    2. Script obtiene tema preferido del localStorage
    3. Aplica las variables CSS correspondientes
    4. Guarda la preferencia
  NO modificar: A menos que quieras cambiar los colores del tema oscuro

MODIFICAR TEXTOS DEL SITIO:

4. CÓMO CAMBIAR IMÁGENES
================================================================================

DÓNDE COLOCAR NUEVAS IMÁGENES:
────────────────────────────

1. Crea una carpeta /assets/images/ si no existe
2. Organiza las imágenes en subcarpetas:
   /assets/images/
   ├── profile/          (fotos de perfil)
   ├── projects/         (imágenes de proyectos)
   ├── services/         (iconos/imágenes de servicios)
   ├── blog/             (imágenes de artículos)
   └── icons/            (iconos del sitio)

3. Sube tus archivos allí


CÓMO REEMPLAZAR IMÁGENES EXISTENTES:
────────────────────────────

PASO 1: Localiza la imagen en el HTML
   Busca: <img src="..." >

PASO 2: Reemplaza la ruta
   Encontrarás rutas como:
   - Rutas externas: src="https://images.pexels.com/..."
   - Rutas locales: src="/assets/images/..."

PASO 3: Copia tu imagen


BUENA PRÁCTICAS PARA IMÁGENES:
────────────────────────────

FORMATO RECOMENDADO:
  - JPG: Para fotos (tamaño reducido)
  - PNG: Para imágenes con transparencia
  - WebP: Formato moderno, mejor compresión

TAMAÑO RECOMENDADO:
  - Foto de perfil: 400x400px (cuadrada)
  - Imágenes de proyecto: 800x600px (responsable)
  - Iconos de servicios: 100x100px
  - Imágenes de blog: 1200x630px (proporción 16:9)

OPTIMIZACIÓN:
  1. Comprime las imágenes antes de subirlas (usar TinyPNG o similar)
  2. Usa nombres descriptivos: perfil-profesional.jpg (no image1.jpg)
  3. Mantén las imágenes en /assets/images/ para mejor organización


EJEMPLOS DE RUTAS:
────────────────────────────

Para cambiar la foto de perfil en sobre-mi/index.html:

ANTES:
  <img src="https://images.pexels.com/photos/3184405/pexels-photo-3184405.jpeg"
       alt="Perfil profesional">

DESPUÉS (opción 1 - imagen local):
  <img src="/assets/images/profile/mi-foto.jpg"
       alt="Foto de perfil profesional">

DESPUÉS (opción 2 - imagen externa):
  <img src="https://tu-dominio.com/static/mi-foto.jpg"
       alt="Foto de perfil profesional">


CAMBIAR ALTURA Y ANCHO DE IMAGEN:
────────────────────────────────

Puedes agregar width y height al HTML:
  <img src="/assets/images/profile/foto.jpg"
       alt="Perfil"
       width="400"
       height="400">

O usar CSS (más recomendado):
  En un <style> o archivo CSS:
  
  img.profile-pic {
    max-width: 400px;
    height: auto;
    border-radius: var(--border-radius-lg);
  }

5. CÓMO CAMBIAR COLORES Y DISEÑO
================================================================================

DÓNDE ESTÁN DEFINIDOS LOS COLORES:
────────────────────────────────

Todo está en /assets/css/main.css en las variables CSS (líneas 16-45).

VARIABLES DE COLOR PRINCIPAL:
────────────────────────────

Paleta de TEMA CLARO (lo que ves por defecto):

:root {
  --color-primary: #1e3a5f;        /* Azul oscuro profesional */
  --color-secondary: #4a6fa5;      /* Azul acero */
  --color-accent: #e67e22;         /* Naranja suave */
  --color-text: #2c3e50;           /* Gris oscuro para texto */
  --color-text-light: #7f8c8d;     /* Gris medio para texto secundario */
  --color-background: #ffffff;     /* Fondo blanco */
  --color-background-alt: #f8f9fa; /* Fondo gris claro alternativo */
  --color-border: #e1e8ed;         /* Bordes suaves */
  --color-success: #27ae60;        /* Verde para éxito */
  --color-warning: #f39c12;        /* Amarillo para advertencias */
  --color-error: #e74c3c;          /* Rojo para errores */
}

Paleta de TEMA OSCURO:
Se define después, cuando se detecta body[data-theme="dark"]

CÓMO CAMBIAR LA PALETA DE COLORES:
────────────────────────────────

PASO 1: Abre /assets/css/main.css

PASO 2: Localiza la sección :root { ... }

PASO 3: Cambia los valores hexadecimales

EJEMPLO - Cambiar azul a rojo:
  ANTES: --color-primary: #1e3a5f;
  DESPUÉS: --color-primary: #c0392b;

EJEMPLO - Cambiar naranja a verde:
  ANTES: --color-accent: #e67e22;
  DESPUÉS: --color-accent: #27ae60;

COLORES RECOMENDADOS:
────────────────────

Azules profesionales:
  #1e3a5f (actual - azul oscuro profesional)
  #2c3e50 (más oscuro)
  #34495e (gris-azul)

Naranjas/Amarillos complementarios:
  #e67e22 (actual - naranja suave)
  #f39c12 (amarillo)
  #e74c3c (rojo coral)

Grises para texto:
  #2c3e50 (oscuro - buena legibilidad)
  #34495e (oscuro alternativo)
  #7f8c8d (gris claro para secundario)

Usa herramientas online para escoger paletas: coolors.co o colorhexa.com


CÓMO CAMBIAR LA TIPOGRAFÍA:
────────────────────────────

En /assets/css/main.css busca:

--font-primary: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-secondary: 'Source Sans Pro', -apple-system, BlinkMacSystemFont, sans-serif;

Cambios simples:
  - 'Inter' por 'Arial', 'Helvetica', 'Verdana'
  - Fuentes populares: 'Poppins', 'Roboto', 'Open Sans'

Para usar Google Fonts:
  1. Ve a https://fonts.google.com
  2. Elige una fuente
  3. Copia el <link> de importación
  4. Pégalo en el <head> de CADA archivo HTML
  5. Actualiza el nombre en --font-primary

EJEMPLO:
  En el <head> de index.html (y otros HTML):
  <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap" rel="stylesheet">
  
  En main.css:
  --font-primary: 'Poppins', sans-serif;


CÓMO CAMBIAR TAMAÑOS DE FUENTE:
────────────────────────────────

En main.css se definen los tamaños:

--font-size-xs: 0.75rem;      /* 12px */
--font-size-sm: 0.875rem;     /* 14px */
--font-size-base: 1rem;       /* 16px */
--font-size-lg: 1.125rem;     /* 18px */
--font-size-xl: 1.25rem;      /* 20px */
--font-size-2xl: 1.5rem;      /* 24px */
--font-size-3xl: 1.875rem;    /* 30px */
--font-size-4xl: 2.25rem;     /* 36px */
--font-size-5xl: 3rem;        /* 48px */

Para aumentar todos los tamaños:
  ANTES: --font-size-base: 1rem;
  DESPUÉS: --font-size-base: 1.1rem;

(Esto escalará todos los demás relativamente)


CÓMO CAMBIAR ESPACIADOS (PADDING, MARGIN):
────────────────────────────────────────────

En main.css:

--space-xs: 8px;
--space-sm: 16px;
--space-md: 24px;
--space-lg: 32px;
--space-xl: 48px;
--space-xxl: 64px;

Para más espaciado:
  ANTES: --space-md: 24px;
  DESPUÉS: --space-md: 32px;

Para menos espaciado:
  ANTES: --space-lg: 32px;
  DESPUÉS: --space-lg: 24px;


CÓMO MODIFICAR COMPONENTES (BOTONES, CARDS):
──────────────────────────────────────────────

BOTONES:

En /assets/css/components.css busca:

.btn {
  padding: var(--space-sm) var(--space-lg);
  border-radius: var(--border-radius-md);
  /* ... */
}

Cambios posibles:
  - Padding: Aumenta o disminuye var(--space-sm)
  - Border-radius: Cambiar a var(--border-radius-lg) para más curvo
  - Colores: Modificar background-color

CARDS:

En /assets/css/components.css busca:

.card {
  border: 1px solid var(--color-border);
  border-radius: var(--border-radius-lg);
  box-shadow: var(--shadow-md);
}

Cambios posibles:
  - border-radius: más o menos curvo
  - box-shadow: cambiar a var(--shadow-lg) para más sombra
  - background-color: cambiar fondo


SOMBRAS DISPONIBLES:

--shadow-sm: 0 1px 3px rgba(0, 0, 0, 0.12);
--shadow-md: 0 4px 6px rgba(0, 0, 0, 0.1);  /* Actual */
--shadow-lg: 0 10px 25px rgba(0, 0, 0, 0.15);
--shadow-xl: 0 20px 40px rgba(0, 0, 0, 0.2);

Use shadow-lg o shadow-xl para más dramatismo.

7. CÓMO FUNCIONA EL JAVASCRIPT DEL PROYECTO
================================================================================

El sitio tiene 3 scripts JavaScript principales que controlan funcionalidades
diferentes. Todos se cargan en cada página HTML.

SCRIPT 1: /assets/js/theme.js (187 líneas)
─────────────────────────────────────────

QUÉ HACE:
  Permite cambiar entre tema claro (light) y oscuro (dark)

CÓMO FUNCIONA:
  1. Usuario hace clic en botón con clase .theme-toggle
  2. Script verifica qué tema está activo
  3. Cambia a el tema opuesto
  4. Aplica variables CSS del tema nuevo
  5. Guarda la preferencia en localStorage del navegador

CONFIGURACIÓN:
  El botón de cambio de tema está en: <button class="theme-toggle">
  Se encuentra en la navegación de cada página

COLORES DEL TEMA OSCURO:
  En main.css, después de :root, hay:
  
  body[data-theme="dark"] {
    --color-primary: #3498db;
    --color-secondary: #2980b9;
    --color-background: #1a1a1a;
    /* ... más variables */
  }

MODIFICAR:
  Si quieres cambiar los colores del tema oscuro:
  Busca en main.css: body[data-theme="dark"] {
  Modifica las variables del color


SCRIPT 2: /assets/js/navigation.js (177 líneas)
────────────────────────────────────────────────

QUÉ HACE:
  Controla toda la navegación del sitio

FUNCIONES PRINCIPALES:

1. MENÚ MÓVIL (Hamburguesa)
   En pantallas pequeñas (<768px):
   - Muestra un botón con 3 líneas (hamburguesa)
   - Al hacer clic, abre/cierra el menú
   - Al hacer clic en un enlace del menú, cierra automáticamente

   Código HTML:
   <button class="navbar-toggle">...</button>

   Cómo funciona:
   - Script busca .navbar-toggle
   - Al hacer clic, agrega clase "active"
   - Esto mostrada el menú .navbar-menu

2. INDICADOR DE PÁGINA ACTIVA
   El enlace del menú resalta la página actual
   
   Ejemplo:
   Si estás en /sobre-mi/, el enlace "Sobre mí" se verá destacado
   
   Cómo funciona:
   - Script obtiene la URL actual
   - Compara con los href de los enlaces del menú
   - Agrega clase "active" al enlace correcto

3. EFECTO SCROLL EN HEADER
   Cuando scrolleas hacia abajo:
   - El header obtiene una sombra
   - Esto indica que hay más contenido arriba
   
   Cómo funciona:
   - Script detecta evento "scroll"
   - Si scrollTop > 0, agrega clase "scrolled" al header
   - CSS muestra una sombra

4. SMOOTH SCROLL
   Los enlaces internos (ej: #servicios) hacen scroll suave
   
   Ejemplo:
   <a href="#servicios"> → anima el scroll hasta #servicios

MODIFICAR:
  La mayoría de funcionalidades NO necesitan modificación
  Excepto:
  - Si cambias la clase "active" del CSS, actualiza en navigation.js
  - Si cambias la clase "scrolled", actualiza en navigation.js


SCRIPT 3: /assets/js/main.js (326 líneas)
──────────────────────────────────────────

QUÉ HACE:
  Maneja animaciones y funcionalidades generales del sitio

FUNCIONES PRINCIPALES:

1. ANIMACIONES DE SCROLL
   Los elementos se animan cuando entran en la pantalla
   
   Cómo funciona:
   - Usa Intersection Observer API (nativa del navegador)
   - Detecta cuando un elemento entra en viewport
   - Agrega clase "animate-in" al elemento
   - CSS anima la entrada
   
   Elementos afectados:
   - Cards (.card)
   - Secciones (section)
   - Párrafos (p)
   
   En main.js busca:
   function initScrollAnimations()
   
   Configuración:
   const observerOptions = {
     threshold: 0.1,        // 10% debe ser visible
     rootMargin: '0px 0px -50px 0px'; // Trigger anticipado
   }
   
   MODIFICAR threshold si quieres que se animen antes o después

2. LAZY LOADING DE IMÁGENES
   Las imágenes se cargan solo cuando van a ser vistas
   
   Cómo funciona:
   - Intersección Observer detecta cuando imagen entra en viewport
   - Carga la imagen en ese momento
   - Mejora performance en páginas con muchas imágenes
   
   En main.js busca:
   function initLazyLoading()
   
   Para usarlo en HTML:
   <img data-src="/assets/images/foto.jpg" alt="...">
   
   NOTA: Las imágenes deben usar data-src en vez de src

3. VALIDACIÓN DE FORMULARIOS
   Los formularios validan antes de enviar
   
   Cómo funciona:
   - Detecta campos requeridos
   - Valida emails
   - Valida que las contraseñas coincidan (si aplica)
   - Muestra mensajes de error
   
   En main.js busca:
   function initForms()
   
   MODIFICAR si necesitas crear nuevos formularios con validaciones personalizadas

4. UTILIDADES GENERALES
   Funciones helper reutilizables
   
   Ejemplos:
   - getScrollPercentage(): obtiene porcentaje scrolleado
   - debounce(): evita ejecutar función demasiadas veces


CÓMO MODIFICAR EL COMPORTAMIENTO DE JAVASCRIPT:
─────────────────────────────────────

EJEMPLO 1: Cambiar tiempo de animaciones

En main.js busca:
  --transition-base: 250ms ease-in-out;

Cambia a:
  --transition-base: 500ms ease-in-out;  // Más lento

Esta variable se usa en CSS para suavidad de transiciones


EJEMPLO 2: Cambiar sensibilidad de scroll animations

En main.js busca:
  threshold: 0.1

Opciones:
  0.05 = Se anima casi al llegar
  0.1  = Actual (10% visible)
  0.25 = Se anima cuando 25% está visible
  0.5  = Se anima cuando está en el medio de la pantalla

EJEMPLO 3: Agregar nueva animación

En HTML:
  <div class="elemento-para-animar">

En main.js, en function initScrollAnimations():
  - Se detecta automáticamente si tiene la clase especial
  - Se añade "animate-in"
  - CSS define la animación
