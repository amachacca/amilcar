Introducción al Análisis Sísmico con OpenSees

OpenSees Python Análisis Sísmico Tutorial

Introducción

OpenSees (Open System for Earthquake Engineering Simulation) es una plataforma de software libre para modelado y análisis de estructuras sometidas a cargas sísmicas. En este artículo, aprenderás los conceptos básicos para comenzar a utilizar OpenSees en tus proyectos de ingeniería estructural.

OpenSees es especialmente útil para análisis no lineal de estructuras, permitiendo modelar el comportamiento real de materiales y elementos estructurales bajo condiciones extremas.

¿Qué es OpenSees?

OpenSees es un framework de software desarrollado por la Universidad de California, Berkeley, que permite realizar análisis estructural avanzado. Sus principales características son:

  • Análisis estático y dinámico no lineal
  • Amplia biblioteca de elementos y materiales
  • Capacidad de modelar interacción suelo-estructura
  • Interfaz con Python mediante OpenSeesPy
  • Software libre y gratuito

Instalación de OpenSeesPy

La forma más sencilla de comenzar con OpenSees es mediante OpenSeesPy, la interfaz Python. Para instalar, simplemente ejecuta: 

pip install openseespy

Una vez instalado, puedes verificar la instalación con: 

import openseespy.opensees as ops
print("OpenSees instalado correctamente")

Ejemplo Práctico: Pórtico Simple

Vamos a crear un modelo simple de un pórtico de un nivel para demostrar las capacidades básicas de OpenSees. Este ejemplo incluye la definición de nodos, elementos y análisis modal.

1. Importar librerías y definir modelo

import openseespy.opensees as ops
import numpy as np

# Limpiar modelo previo
ops.wipe()

# Crear modelo (2 dimensiones, 3 grados de libertad por nodo)
ops.model('basic', '-ndm', 2, '-ndf', 3)

2. Definir geometría

# Nodos (tag, x, y)
ops.node(1, 0.0, 0.0)    # Base izquierda
ops.node(2, 4.0, 0.0)    # Base derecha
ops.node(3, 0.0, 3.0)    # Techo izquierdo
ops.node(4, 4.0, 3.0)    # Techo derecho

# Fijar base
ops.fix(1, 1, 1, 1)
ops.fix(2, 1, 1, 1)

3. Definir material y secciones

# Material elástico (tag, E)
E = 2.1e11  # Acero en Pa
ops.uniaxialMaterial('Elastic', 1, E)

# Propiedades de sección
A = 0.01   # Área
I = 8.33e-5  # Inercia

# Transformación geométrica
ops.geomTransf('Linear', 1)

4. Crear elementos

# Elementos (tag, nodo_i, nodo_j, A, E, I, transf)
ops.element('elasticBeamColumn', 1, 1, 3, A, E, I, 1)  # Columna izq
ops.element('elasticBeamColumn', 2, 2, 4, A, E, I, 1)  # Columna der
ops.element('elasticBeamColumn', 3, 3, 4, A, E, I, 1)  # Viga

5. Análisis modal

# Análisis de valores propios
numModes = 3
eigenValues = ops.eigen(numModes)

# Calcular periodos
import math
periods = [2 * math.pi / math.sqrt(ev) for ev in eigenValues]

print("Periodos de vibración:")
for i, T in enumerate(periods, 1):
    print(f"Modo {i}: T = {T:.3f} segundos")

Interpretación de Resultados

El análisis modal nos proporciona información fundamental sobre el comportamiento dinámico de la estructura:

  • Periodo fundamental: Indica la frecuencia natural de vibración
  • Modos de vibración: Describen las formas en que la estructura se deforma
  • Masa modal: Cantidad de masa que participa en cada modo

Próximos Pasos

Este ejemplo básico es solo el comienzo. OpenSees permite realizar análisis mucho más complejos, incluyendo:

  • Análisis tiempo-historia con acelerogramas reales
  • Análisis pushover para evaluar capacidad
  • Modelado de materiales no lineales (concreto, acero)
  • Análisis de interacción suelo-estructura
  • Estructuras 3D complejas

Conclusión

OpenSees es una herramienta poderosa para el análisis estructural avanzado. Aunque la curva de aprendizaje puede ser pronunciada, el dominio de esta herramienta te permitirá realizar análisis que serían imposibles con software comercial convencional.

La integración con Python mediante OpenSeesPy facilita enormemente la automatización de análisis y el post-procesamiento de resultados, convirtiéndolo en una herramienta indispensable para ingenieros estructurales modernos.
