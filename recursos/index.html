Plantillas, hojas de cálculo y herramientas listas para usar

Plantilla Excel - Diseño de Vigas

Hoja de cálculo automatizada para diseño de vigas de concreto armado según ACI 318. Incluye verificación de cortante y flexión.

Excel Concreto ACI 318
Descargar

Script Python - Análisis Modal

Script para análisis modal automático con OpenSeesPy. Genera gráficos de modos de vibración y exporta resultados.

Python OpenSees Modal
Descargar

Plantilla Excel - Diseño de Columnas

Diseño de columnas de concreto armado con diagrama de interacción P-M. Incluye efectos de esbeltez.

Excel Columnas Diagrama P-M
Descargar

Calculadora - Conexiones de Acero

Hoja de cálculo para diseño de conexiones soldadas y apernadas según AISC 360-16.

Excel Acero AISC
Descargar

Script Python - Generación de Reportes

Automatiza la generación de reportes estructurales en formato Word con Python y python-docx.

Python Reportes Word
Descargar

Plantilla Excel - Losas en 2 Direcciones

Diseño de losas macizas en dos direcciones por el método de coeficientes ACI.

Excel Losas ACI
