Edificio Residencial Torre Central

Diseño estructural completo de edificio de 12 pisos en concreto armado con análisis sísmico avanzado

Descripción del Proyecto

El Edificio Torre Central es una estructura residencial de 12 pisos diseñada para albergar 36 departamentos de lujo en una zona sísmica de alta peligrosidad. El proyecto requirió un análisis sísmico detallado y optimización estructural para cumplir con las normativas vigentes mientras se mantenía la eficiencia económica.

Ubicación

Lima, Perú - Zona sísmica 4 (Alta peligrosidad)

Tipo de Estructura

Sistema dual: Pórticos de concreto armado + muros de corte

Cliente

Inmobiliaria Constructora XYZ S.A.C.

Datos Técnicos

Altura total: 36 metros
Área construida: 4,200 m²
Número de pisos: 12 + sótano
Material principal: Concreto armado f'c=280 kg/cm²
Cimentación: Zapatas conectadas + vigas de cimentación
Duración diseño: 6 meses

Normativa Utilizada

  • Norma E.030 - Diseño Sismorresistente
  • Norma E.060 - Concreto Armado
  • ACI 318-19 - Building Code Requirements
  • Norma E.050 - Suelos y Cimentaciones

Software Utilizado

ETABS v20 SAFE AutoCAD Python Excel

Análisis y Resultados

Análisis Estructural

  • Análisis modal: Identificación de 12 modos de vibración principales
  • Análisis espectral: Evaluación según espectro de diseño sísmico
  • Análisis estático: Verificación de cargas de gravedad
  • Análisis dinámico: Respuesta temporal ante sismos

Resultados Principales

  • Deriva máxima: 0.005 (< 0.007 permitido)
  • Periodo fundamental: 0.82 segundos
  • Factor de reducción: R = 7 (sistema dual)
  • Ratio acero/concreto: Optimizado a 95 kg/m³

Galería del Proyecto

Conclusiones

El proyecto del Edificio Torre Central fue completado exitosamente, cumpliendo con todos los requisitos normativos y de seguridad estructural. El sistema dual propuesto permitió optimizar el uso de materiales mientras se garantizaba un comportamiento sísmico adecuado.

Las derivas obtenidas estuvieron muy por debajo de los límites permitidos, lo que indica un diseño conservador y seguro. La implementación de herramientas de automatización en Python permitió reducir el tiempo de diseño en un 30%.

Este proyecto demostró la efectividad de combinar análisis estructural avanzado con optimización económica, resultando en una estructura segura, eficiente y económica.
